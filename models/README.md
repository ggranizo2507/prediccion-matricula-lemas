# Modelos

| Archivo | Descripción |
|---|---|
| `best_model.pkl` | Modelo final entrenado con **datos sintéticos**; es el que usa la app pública (Fase 2) |
| `model_v1.pkl` | Versiones anteriores para comparación |

Los modelos entrenados con datos reales de LEMAS se guardan solo en el entorno autorizado, con el sufijo `_real`, que `.gitignore` bloquea. Un modelo puede memorizar casos individuales, por eso no se publica.
